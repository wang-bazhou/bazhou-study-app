# bazhou 学习软件

一个**章节式课程 + 内嵌判题**的 Windows 桌面软件：把知识从「平铺的文章」变成
「可验收的进度条」——每章有知识点、常见陷阱，练习直接在软件里写代码、点一下判题
就知道对不对，做过哪些题会自动记进度。

双击就能用：原生窗口、不用浏览器、不用 localhost、看内容不需要联网。

## 下载

| 文件 | 说明 |
|---|---|
| `bazhou-user-0.1.0.zip` | 软件本体，解开即用 |
| `SHA256SUMS.txt` | 校验和（可选：用来确认下载过程没坏） |

下载后**解压到任意目录**（路径里别用特殊字符），双击里面的 `bazhou.exe` 就能开始。

## 第一次打开

1. 双击 `bazhou.exe`（首次启动会创建保存进度用的目录）；
2. 打开任意一章的「测试」页。若提示「还不能判题」，点一下 **现在准备判题环境** ——
   软件会自己下载判题所需的组件（约 192 MB，来自官方源并校验 sha256），
   装到**软件自己的目录**里。**不需要你预先安装 Python 或 C++ 编译器**，
   也不会改动系统环境（不写 PATH、不改注册表）；
3. 之后就能正常做题、判题了。

> L10 系列是 Linux 系统编程，需要 WSL2；没装也能看正文、做那几章的选择题。

## 里面有什么

| 内容 | 规模 |
|---|---|
| C++ 主线课程 | L0 ~ L13 共 88 章（含 12 个 Level 综合挑战） |
| 算法训练场 | A0 ~ A11 共 12 段、119 道题（每题多组测试，专打边界；A11 是力扣经典题型，离线可做） |
| 力扣题单 | 112 道（官方「热题 100」全覆盖），按章节推荐、点标题跳转力扣 |
| 白板 | 内容区右边可以随时开一栏，自己写代码点一下就运行（不判对错、不计进度；代码自动保存） |

## 你的数据在哪

| 数据 | 位置 |
|---|---|
| 学习进度与设置 | `%APPDATA%\bazhou\`（换电脑把这个目录拷过去就能接着学） |
| 运行日志 | `%LOCALAPPDATA%\bazhou\logs\debug.log`（软件「设置」页也能一键打开） |

**界面全白**是这类程序最常见的故障：先关掉多余窗口重开一次（同一时刻只能开一个）；
仍然不行就把上面的日志文件带上一起反馈。
